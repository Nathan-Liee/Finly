<p align="center">
  <strong>Finly</strong> adalah aplikasi manajemen keuangan pribadi modern yang dirancang untuk kecepatan, keamanan, dan kemudahan penggunaan. Fokus pada stabilitas rendering mobile dan pengalaman pengguna yang intuitif.

---

## ✨ Fitur Utama

- 📱 **Mobile First & PWA Ready** - Install di home screen layaknya aplikasi native.
- 🌓 **Dark/Light Mode** - Antarmuka yang adaptif dengan preferensi mata Anda.
- 📊 **Visualisasi Data** - Pantau arus kas melalui Bar Chart dan Summary Cards yang informatif.
- 🔍 **Pencarian Cepat** - Filter transaksi berdasarkan kategori, catatan, atau metode secara instan.
- 💾 **Backup & Restore** - Ekspor data ke JSON/CSV dan impor kembali kapan saja.
- ⚡ **Offline Support** - Tetap bisa diakses meski tanpa koneksi internet (Service Worker).

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite 8
- **Styling:** CSS3 (Custom Keyframe Animations)
- **Database:** Supabase (Backend-as-a-Service)
- **Deployment:** Vercel

## 📦 Instalasi Lokal

```bash
# Clone repository
git clone https://github.com/Nathan-Liee/kas-app.git

# Masuk ke direktori
cd kas-app

# Install dependensi
npm install

# Jalankan dev server
npm run dev
```
