# Screenshot Placeholders

Ganti file-file ini dengan screenshot asli dari app:

- `home-light.png` → Screenshot halaman Home (light mode)
- `home-dark.png` → Screenshot halaman Home (dark mode)
- `report-light.png` → Screenshot halaman Laporan (light mode)
- `report-dark.png` → Screenshot halaman Laporan (dark mode)
- `settings-light.png` → Screenshot halaman Pengaturan (light mode)
- `settings-dark.png` → Screenshot halaman Pengaturan (dark mode)

> Tips: Buka dev server di browser, toggle dark mode di Pengaturan, lalu screenshot atau gunakan DevTools > Capture screenshot.
